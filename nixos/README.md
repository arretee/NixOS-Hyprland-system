# NixOS Configuration
Custom NixOS configuration build for personal use.

The configuration is build for personal usage and as learning project as well. 

# Design
## Window Manager - Hyprland
```
    wofi 	        # App launcher
    waybar	        # Status bar
    mako 	        # Notifications
    hyprpaper  	    # Wallpaper
    grim 	        # Screenshots
    slurp 	        # Selecet screen area
    wl-clipboard	# Clipboard tools
```

## Shell and terminal
```
    kitty           # Terminal 
    zsh             # Shell
```
